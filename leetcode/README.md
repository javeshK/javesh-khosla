# LeetCode solutions

This folder receives auto-synced LeetCode submissions via [LeetHub 2.0](https://github.com/arunbhardwaj/LeetHub-2.0).

## Setup

1. Install [LeetHub v2 for Chrome](https://chromewebstore.google.com/detail/leethub-v2/mhanfgfagplhgemhjfeolkkdidbakocm) or [Firefox](https://addons.mozilla.org/en-CA/firefox/addon/leethub-2-0-for-firefox/).
2. Authorize GitHub (prefer a fine-grained PAT scoped to this repo only).
3. Select repository: `javeshK/javesh-khosla`.
4. Set the destination folder to `leetcode`.

When you get "Accepted" on a problem, LeetHub commits your solution here automatically.
